    How it works

    1. A narrow-band spectrogram is searched for falling tones. Each tone is fitted with a straight-pass Doppler model for base tone, speed, closest distance and closest-approach time.
    2. Each tone is scored against the same search run on the time-reversed recording. A real flyover only falls in pitch, so that run measures what noise alone can produce.
    3. For every grid point and every start time, the exact curve that point would have heard is predicted from each ADS-B track, including wind and temperature. All flyovers share one clock.
    4. Direct matching skips step 1. It slides each aircraft's predicted curve over the spectrogram inside the tone bands, so faint or broken jet tones still count.

    Read the answer carefully

    • One straight pass with no timestamp fixes only your distance from the flight line. Add the time or a second flyover.
    • Even with the time, a straight level pass cannot tell which side of the track you were on, so expect two areas.
    • The 95% region assumes the flight data is right. Barometric altitude, coarse tracks and gusty wind make the real uncertainty larger.
    • On real recordings (field recordings with published coordinates, plus ADS-B Exchange history), direct matching put a Toulouse departure recording 0.9 km from the recordist. It named the right aircraft and start time, using the logged minute ±1 and two marked tone bands. A London recording did not match: no logged aircraft explains its tone from the true spot. A street microphone gave nothing usable over traffic noise.

    Privacy

    • This locates people. Only analyse recordings you have the right to analyse.
    • To protect your own clips: strip the creation time and location metadata, and cut out stretches where a plane is audible. Strong noise suppression also helps. A simple high-pass filter usually does not.
